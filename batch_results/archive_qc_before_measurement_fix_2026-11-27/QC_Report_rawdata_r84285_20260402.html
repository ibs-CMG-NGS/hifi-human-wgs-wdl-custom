📊 P1 (ZMW Productivity) 이상

❌ P1 < 40% — Under-loading (과소 로딩)

  • 빈 ZMW(P0)가 증가하여 데이터 생산량이 감소
  • On-Plate Loading Concentration (OPLC)을 높여 재실험
  • 처음 배치 실험 시 Loading Titration으로 최적 OPLC 결정 권장
  • 목표 P1 범위: 55–65% (첫 실험 시), 최적화 후 50–70%
원인: 샘플 농도 부족, 불충분한 어닐링, 라이브러리 희석 과다

❌ P1 > 80% — Over-loading (과다 로딩)

  • Multi-loaded ZMW(P2) 증가 → 배경 잡음 상승, 데이터 품질 저하
  • Mean Polymerase Read Length가 현저히 감소할 수 있음
  • OPLC를 낮추어 재실험
  • P2가 5% 초과 시 과다 로딩으로 판단
원인: 샘플 농도 과다, OPLC 과다 설정

🧪 Control Read 이상

❌ Control Read Count < 500

  • 장비 또는 소모품 문제 가능성 높음 → 장비 점검 우선
  • Revio Sequencing Control 시약 상태 확인 (유통기한, 보관 조건)
  • SMRT Cell tray 및 Sequencing plate 상태 확인
  • 샘플 OPLC가 너무 높으면 샘플이 Control과 경쟁 → Control count 감소 가능
원인: 소모품 불량, 장비 이상, 샘플 과다 로딩

⚠️ Control Read Length < 50 kb (24-hr 기준)

  • 장비 및 소모품 성능 저하 의심
  • Sequencing plate 개봉 후 사용 시간 확인 (Open Limit: 200시간)
  • Polymerase kit 유통기한 및 보관 상태 점검
  • Control Read Length ≥ 40 kb이면 샘플 문제에 집중하여 점검
원인: 소모품 노후화, 부적절한 보관 (실온 노출, 빛 노출, 표면 오염)

📉 HiFi Yield / Read Length 이상 (Control 정상인 경우)

⚠️ HiFi Yield 낮음 (<100 Gb, 24-hr 15–20 kb WGS 기준)

  • Control이 정상이면 샘플 품질 또는 라이브러리 문제
  • Insert size distribution 확인: Read Length Density plot 참조
  • P1이 정상 범위(50–70%)인지 확인 — P1 낮으면 OPLC 조정이 우선
  • 15–20 kb library: 기대 Yield 100–120 Gb / SMRT Cell (24-hr)
  • Yield = P1 reads × Polymerase Read Length 임을 참고
원인: 낮은 P1, 짧은 insert size, DNA 품질 불량, 로딩 농도 부적절

⚠️ HiFi Read Length 짧음 (<15 kb)

  • 라이브러리 insert size가 목표값보다 작음 → 라이브러리 준비 재검토
  • gDNA 추출 과정에서 전단(shearing) 과다 여부 확인
  • SMRTbell 라이브러리 준비 시 bead cleanup 조건 확인
  • 5 kb 미만의 minor peak는 잔존 short fragment로 정상 범위일 수 있음
  • Bioanalyzer/Fragment Analyzer로 라이브러리 size distribution 재확인
원인: gDNA 분해, 과도한 전단, 라이브러리 준비 조건 불량

🔬 Read Quality / Q30+ 이상

⚠️ Median Read Quality < Q30 또는 Q30+ Bases < 90%

  • HiFi read는 QV ≥ 20이 최소 요건이며 일반적으로 QV 30–35 기대
  • Mean passes가 낮으면(≤5) insert size에 비해 Polymerase Read Length가 짧은 것
  • 소모품(Polymerase kit, Sequencing plate) 상태 재점검
  • Control concordance ≥ 88% 여부를 함께 확인
원인: 낮은 subread pass 수, 소모품 품질 저하, DNA 손상

⚠️ Missing Adapter ≥ 10%

  • SMRTbell template에서 어댑터 1개만 검출된 ZMW 비율이 높음
  • 라이브러리 준비 시 어댑터 라이게이션 효율 확인
  • SMRTbell prep kit 시약 상태 및 프로토콜 준수 여부 재검토
  • < 5%이면 정상, 5–10%이면 주의 모니터링
원인: 라이게이션 효율 저하, 불완전한 SMRTbell 형성, 시약 불량

📉 % Active ZMWs 급격한 감소 (Run Preview 확인 시)

ℹ️ Active ZMW 급감 (Run 중 모니터링)

  • 최적 로딩 시 최대 % Active ZMWs ≈ 40% (P1 50–75% 해당)
  • 급격한 감소는 샘플 품질 문제 또는 소모품 불량 신호
  • gDNA 과도한 손상 또는 Polymerase inhibitor 잔류 가능성
  • bead cleanup 조건 재검토 (샘플 준비 단계부터 오염원 추적)
  • Sequencing plate 보관 조건 확인 (실온 노출, 빛 노출 금지)
원인: DNA 손상, Polymerase inhibitor, 소모품 부적절 보관
